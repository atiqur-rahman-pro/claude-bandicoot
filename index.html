🎮 About Claude Bandicoot

Claude Bandicoot is a browser-based endless runner game inspired by Claude AI and classic lane-based 3D platform games. Built with HTML, CSS, JavaScript, and Three.js, the game challenges players to survive increasingly difficult gauntlet loops, collect Wumpa fruit, smash wooden crates, avoid TNT explosives, and achieve high scores in a real-time WebGL environment.

✨ Features

  • Claude AI-inspired 3D browser runner
  • Endless runner gameplay loops
  • Progressive difficulty scaling
  • Wumpa fruit collection & crate physics
  • Dynamic obstacle hazards & TNT crates
  • Keyboard & mobile touch controls
  • 100% Free to play in browser
  • Open-source GitHub project
